# Музыка

Сюда кладутся твои треки. Пока файлов нет, игра синтезирует свой — 32
такта на 108 ударов, с гармонией из четырёх ступеней и разделами, где
барабана нет вовсе. Пустые такты там важнее полных: короткая петля с
барабаном в каждом такте давит через минуту, даже если сама по себе
приятная.

Темп, громкость, эхо и переключение по уровням уже работают, файлу
остаётся занять готовое место.

## Как подложить

1. Положить сюда файл: `floor-1.mp3` (или `.ogg`, `.m4a` — что играет браузер).
2. Скопировать пример манифеста и вписать треки:

```sh
cp avto/music/manifest.example.json avto/music/manifest.json
```

3. Обновить, если нужно, `track` у уровня — это номер трека в манифесте.
   У встроенного этажа он `0` (`avto/src/levels.js`).

Больше ничего менять не надо: `src/audio.js` при старте сам запрашивает
`music/manifest.json`, и если файл есть — играет его вместо синтеза.

## Что учесть

- **Луп.** Трек играет по кругу без склейки: обрежьте хвост по такту,
  иначе на стыке будет слышна пауза.
- **Громкость.** Музыка идёт в общую шину и приглушается в меню. Нормализуйте
  треки между собой, игра их не выравнивает.
- **Вес.** Каталог выкладывается вместе с игрой (`deploy.sh`, список `PAYLOAD`).
  Три минуты в 128 kbps — около 3 МБ; это тот же порядок, что вся остальная
  игра, и заметно на мобильном интернете.
- **Права.** Файлы уезжают на публичный сайт. Своё — можно, чужое — нет.

`manifest.json` в git не отслеживается вместе с аудио: положите файлы и
манифест локально, выкладка заберёт их из дерева.

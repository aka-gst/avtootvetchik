# АВТООТВЕТЧИК

Быстрый экшен сверху вниз. С одного удара умирают все, включая игрока;
проигрыш стоит полсекунды и начинается заново. Отсылка к жанру — в темпе,
палитре и крови, которая остаётся до конца попытки; ни одного чужого
пикселя или сэмпла в игре нет, всё рисуется фигурами и синтезируется.

Название рабочее.

## Запустить

Ни сборки, ни зависимостей — нужен только статический сервер, потому что
игра собрана из ES-модулей, а их браузер не грузит с `file://`.

```sh
python3 -m http.server 4180
```

Дальше `http://localhost:4180/`. На телефоне — тот же адрес с IP машины
(`ifconfig | grep 'inet '`), телефон должен быть в той же сети.

Игра живёт на сайте по адресу [aka-gst.ru/avto/](https://aka-gst.ru/avto/),
там она лежит копией этого репозитория в каталоге `avto/`.

## Что уже есть

- Бой: кулаки сбивают с ног, бита и пуля убивают, лежачего добивает что угодно.
- Оружие подбирается с пола и бросается; брошенное сбивает с ног.
- Враги видят сектором, слышат выстрел через стены и сбегаются на крик.
- Стрелок держит дистанцию и стреляет с замахом — есть время уйти с линии.
- Этаж считается сданным, когда все мертвы и игрок вышел тем же путём.
- Управление: клавиши, мышь или два пальца — на выбор, переключаться не надо.
- Счёт с цепочками и рангом от D до S, рекорд этажа хранится в браузере.
- Музыка синтезируется на месте, пока нет файлов (`music/README.md`).

Чего ещё нет: редактора уровней и второго этажа.

## Как устроено

Ванильные ES-модули, ни сборки, ни зависимостей.

| Файл | За что отвечает |
|---|---|
| `src/main.js` | цикл кадра, камера, прицел, экраны между попытками |
| `src/world.js` | тела, столкновения, оружие, смерть — без единой строки отрисовки |
| `src/ai.js` | зрение, слух, состояния врага, волна поиска пути |
| `src/render.js` | холст: два запечённых слоя уровня и всё живое между ними |
| `src/input.js` | клавиатура, мышь, плавающие стики, экранные кнопки |
| `src/audio.js` | синтезированный трек, эффекты, переключение на файлы |
| `src/level.js` | формат уровня и код комнаты |
| `src/levels.js` | встроенные этажи, нарисованные картинкой |
| `src/score.js` | цепочки, бонусы, ранг, рекорды |

Мир ничего не знает про экран и ввод: `update(world, dt, intent)` двигает
партию, а `intent` может прийти хоть от пальца, хоть от бота в прогоне.
Поэтому игру можно проверять без браузера.

## Код уровня

Уровень целиком лежит в строке: сетка и сущности пакуются в биты, биты —
в base64url. Сервер не нужен, и код, записанный год назад, откроется
завтра. Плата — длина: этаж 36×24 с восемью объектами выходит в 228
символов.

Проверить руками:

```sh
node -e "import('./src/levels.js').then(async m => { const l = await import('./src/level.js'); console.log(l.encode(m.CAMPAIGN[0])) })"
```

Открыть чужой этаж: `#l=<код>` в адресе. Свой код игра показывает на паузе,
там же кнопка «КОПИЯ». Битый код не откроется молча — в хвосте лежит
контрольный байт, и игра скажет, что строка повреждена.

Формат описан в шапке `src/level.js`. Номера тайлов и сущностей менять
нельзя — старые коды перестанут читаться; добавлять новые можно.

## Управление

| | |
|---|---|
| WASD | идти |
| стрелки | целить (и идти, если WASD не нажат) |
| пробел, J или ЛКМ | бить и стрелять, удержание — очередь |
| мышь | целить, пока ей двигают |
| E | подобрать с пола |
| Q или ПКМ | бросить оружие |
| R | начать этаж заново |
| Esc | пауза и код этажа |

Клавиатура работает как два стика: левая рука ведёт, правая целит. Мышь
нужна не всем и не всегда — на ноутбуке трекпадом прицел не удержать,
поэтому она перехватывает наводку, только пока ей действительно двигают
или держат кнопку. Как только нажата стрелка, прицел переходит к клавишам
без всяких переключателей.

Если не трогать ни мышь, ни стрелки, игрок целится туда, куда бежит, и
доводит прицел до ближайшей цели сам — этого хватает, чтобы играть одной
рукой на WASD и пробеле.

На телефоне — два плавающих стика: левый ведёт, правый целит и бьёт сам,
когда цель под прицелом. Кнопки «взять» и «бросить» стоят столбиком у
правой кромки, подальше от того угла, где лежит большой палец.

## Счёт

Очки платят не за аккуратность, а за темп. Убийство стоит 100, добивание
лежачего — 150, и всё это множится на длину цепочки: каждое следующее
убийство поднимает множитель, четыре секунды без крови обнуляют его.
Врага, которого застрелил свой же, засчитывают за 50 — заслуга косвенная.

В конце этажа добавляются бонусы: за время быстрее норматива
(15 секунд плюс 7 на каждого), за разные орудия, за максимальную цепочку,
за пройденный без единого выстрела этаж и за победу с первой попытки.

Ранг считается от норматива в 900 очков на врага: S с 1,2 норматива,
дальше A, B, C и D. Тупой бот, зачищающий этаж по прямой, набирает C —
всё, что выше, требует цепочек и добиваний.

Рекорд хранится в браузере и привязан не к названию этажа, а к его коду:
чужой уровень, пришедший ссылкой, заводит собственную строку.

## Свой этаж

Пока редактора нет, этажи рисуются картинкой в `src/levels.js`:

```
# стена   . пол    , ковёр   = мебель   | стекло
+ дверь   X выход  @ вход    t громила  s стрелок
b бита    p пистолет
```

Строки должны быть одной длины, вход `@` обязателен. Проверка связности —
в прогоне `tests/sim.mjs`.

## Защита от утечек

Репозиторий публичный, поэтому проверка на секреты и личные данные стоит в
`git`, а не держится на внимательности — тот же хук, что и на сайте:

```sh
git config core.hooksPath .githooks
mkdir -p ~/.config/aka-gst && cp .githooks/private-words.example ~/.config/aka-gst/private-words.txt
chmod 600 ~/.config/aka-gst/private-words.txt
```

Список лежит вне дерева игры: она копируется на сервер файлами, а не
индексом git, и внутри `.githooks/` он оказался бы на публичном хостинге.

## Проверка

```sh
node tests/sim.mjs
node tests/input.mjs
```

Первый прогоняет бой без браузера: удары, выстрелы, поиск пути, полную
зачистку ботом, начисление очков и бюджет кадра. Второй подсовывает вводу поддельный DOM и
проверяет клавиши, стики и экранные кнопки.

Ни requestAnimationFrame, ни холст в прогонах не участвуют — они молчат
о том, как игра выглядит, но говорят, работает ли она.

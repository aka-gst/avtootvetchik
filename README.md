# ТЕХНОМАГИЯ

Изометрический экшен про техно-магов в ночном кибер-парке. С одного
касания умирают все, включая игрока; проигрыш стоит полсекунды и
начинается заново.

Оружия у мага нет вовсе. Есть очередь из трёх стихий, и две независимые
оси: **состав решает вещество** — что прилетело, **порядок решает форму** —
куда прилетело. Вещество не исчезает после попадания: лужа, пожар, лёд и
грязь остаются на полу и встречаются со следующим заклинанием. Разряд идёт
по воде и не разбирает своих.

Ни одного чужого пикселя или сэмпла: всё рисуется фигурами и
синтезируется на месте.

## Запустить

Ни сборки, ни зависимостей — нужен только статический сервер, потому что
игра собрана из ES-модулей, а их браузер не грузит с `file://`.

```sh
python3 serve.py
```

Дальше `http://localhost:4190/`. На телефоне — тот же адрес с IP машины
(`ifconfig | grep 'inet '`), телефон должен быть в той же сети.

Свой сервер нужен из-за кэша. `python3 -m http.server` кэширование не
запрещает, а в index.html строкой запроса версионируется только точка
входа: импорты внутри неё — нет, и правка в `src/*.js` может не доехать до
вкладки. На этом однажды потеряли время, разбираясь, почему в браузере не
работает то, что уже исправлено. `serve.py` отдаёт всё с `no-store`.

Игра живёт на сайте по адресу
[aka-gst.ru/technomagic/](https://aka-gst.ru/technomagic/) — там она лежит
копией этого репозитория в каталоге `technomagic/`.

## Что уже есть

- Оружия у игрока нет: всё, что он умеет, — очередь стихий.
- Пять стихий, двадцать пять составов: **состав решает вещество, порядок — форму**.
- Вещество живёт после попадания: лужа, пожар, лёд, грязь, пар.
- Разряд идёт по воде — налитая заранее лужа превращает его в оружие по площади.
- Книга заклинаний на `B`: что выпустил хоть раз, то и записано.
- Десять именных заклинаний — точные пары «вещество · форма» с особым действием.
- Одиночный плевок тихий, большие формы слышно через весь этаж.
- Враги видят сектором, слышат шум и сбегаются на крик. Мебель они обходят: сквозь неё видно, но не простреливается.
- Стойкость: своей стихией врага не убить, нужен любой другой цвет.
- Этаж считается сданным, когда все мертвы и игрок вышел тем же путём.
- Управление: клавиши, мышь или два пальца — на выбор, переключаться не надо.
- Четыре этажа, и каждый следующий даёт новую стихию.
- Счёт с цепочками и рангом от D до S, рекорд этажа хранится в браузере.
- Вызов по ссылке: этаж и твой результат уезжают одной строкой другому человеку.
- Музыка синтезируется на месте, пока нет файлов (`music/README.md`).

Чего ещё нет: редактора уровней.

## Как устроено

Ванильные ES-модули, ни сборки, ни зависимостей.

| Файл | За что отвечает |
|---|---|
| `src/main.js` | цикл кадра, камера, прицел, экраны между попытками |
| `src/world.js` | тела, столкновения, оружие, смерть — без единой строки отрисовки |
| `src/ai.js` | зрение, слух, состояния врага, волна поиска пути |
| `src/render.js` | холст: два запечённых слоя уровня и всё живое между ними |
| `src/input.js` | клавиатура, мышь, плавающие стики, экранные кнопки |
| `src/aim.js` | помощь прицела: доводка, доворот удара, ближняя угроза |
| `src/magic.js` | стихии, составы, вещества и формы |
| `src/field.js` | поле: лужи, пожар, лёд, грязь, пар и правила их встречи |
| `src/book.js` | книга: что игрок уже нашёл, и как это показать |
| `src/render.js` | изометрия: проекция, порядок глубины, маги и материалы |
| `src/audio.js` | синтезированный трек, эффекты, переключение на файлы |
| `src/level.js` | формат уровня и код комнаты |
| `src/levels.js` | встроенные этажи, нарисованные картинкой |
| `src/score.js` | цепочки, бонусы, ранг, рекорды |
| `src/challenge.js` | ссылка-вызов: упаковка результата и разбор адреса |

Мир ничего не знает про экран и ввод: `update(world, dt, intent)` двигает
партию, а `intent` может прийти хоть от пальца, хоть от бота в прогоне.
Поэтому игру можно проверять без браузера.

## Код уровня

Уровень целиком лежит в строке: сетка и сущности пакуются в биты, биты —
в base64url. Сервер не нужен, и код, записанный год назад, откроется
завтра. Плата — длина: этаж 36×24 с восемью объектами выходит в 228
символов.

Проверить руками:

```sh
node -e "import('./src/levels.js').then(async m => { const l = await import('./src/level.js'); console.log(l.encode(m.CAMPAIGN[0])) })"
```

Открыть чужой этаж: `#l=<код>` в адресе. Свой код игра показывает на паузе,
там же кнопка «КОПИЯ». Битый код не откроется молча — в хвосте лежит
контрольный байт, и игра скажет, что строка повреждена.

Формат описан в шапке `src/level.js`. Номера тайлов и сущностей менять
нельзя — старые коды перестанут читаться; добавлять новые можно.

Версия 3 расширила тип клетки до четырёх бит: предметов стало больше
восьми. Версия 2 добавила в код маску стихий — какие из пяти даёт этаж. Стихии
живут в коде, а не в сохранённом прогрессе, и причина простая: этаж уезжает
по ссылке чужому человеку и обязан открыться у него так же, как у автора.
Прогресс, лежащий в браузере, сделал бы один и тот же код разной игрой у
двух людей.

Коды версии 1 читаются по-прежнему и получают те три стихии, при которых
были записаны. Это не обещание на словах: в `tests/sim.mjs` лежит
замороженная строка кода версии 1, собранная отдельной реализацией
формата, и прогон её открывает.

## Управление

| | |
|---|---|
| WASD | идти |
| ← ↑ → ↓ и правый ⇧ | набрать стихию: огонь, вода, ветер, земля, молния (или 1–5) |
| пробел, ⏎, J или ЛКМ | выпустить набранное; удержание — очередь выпусков |
| Q или Backspace | сбросить набранное |
| Tab | сменить цель: сначала живые, потом бочки, валуны и кристаллы |
| мышь | целить, пока ей двигают |
| R | начать этаж заново |
| Esc | пауза и код этажа |

Руки разведены по половинам клавиатуры: левая ведёт, правая набирает и
выпускает — пробел приходится под большой палец той же руки, что лежит на
стрелках. Четыре стихии заняли все четыре стрелки, пятая — правый шифт под
ними: слэш пробовали и убрали, до него приходится тянуться через весь
нижний ряд, а шифт лежит там же, где и так стоит ладонь. Сброс очереди
уехал на Q — под мизинец левой руки, которая и так лежит на WASD. Целиться при этом нечем — и не нужно: прицел ведёт
автонаводка. Игрок смотрит туда, куда бежит, и доводит прицел до ближайшей
цели сам; стоя на месте, поворачивается к подошедшему вплотную, а с
набранной очередью смотрит дальше — демона надо куда-то выпустить.

Мышь остаётся полноправным способом целиться и перехватывает наводку,
пока ей двигают или держат кнопку. Специально переключаться не надо ни в
одну сторону.

Выпуск всегда ручной: набранное — это ставка, и тратить её за игрока
игра не имеет права.

Целью может быть не только живой. Бочку, валун и кристалл ломают тем же
заклинанием, что и врага, — а попасть по ним с клавиатуры было нельзя
вовсе: прицел держался за тела и на неподвижное не наводился никогда.
Обучалка при этом просила разбить бочку, и сделать это можно было только
мышью — нашёл это живой человек за игрой, а не прогон. Теперь предметы
стоят в том же списке целей, но позади живых: пока в комнате есть кто
живой, взгляд держится за него, а Tab перебирает остальных.

Пять клавиш стихий висят внизу экрана всегда. Состав — весь язык игры, и
держать его в памяти игрок не обязан: пока клавиши на экране, заклинание
собирается глазами. Недоступные на этаже тушатся, а не прячутся — видно,
что стихий пять и какие ещё впереди.

Правило выбора цели: направление задаёт игрок, расстояние только разнимает
близкие по углу. Сектор доводки зависит от того, чем целятся — у мыши он
почти нулевой, у стрелок и бега широкий, потому что там всего восемь
направлений и одно соответственно. Удар вдобавок доворачивается на того,
кто стоит в шаге сбоку, если в самом секторе замаха никого нет.

На телефоне — два плавающих стика прямо по полю: левый ведёт, правый целит
и бьёт сам, когда цель под прицелом.

Экран телефона вытянут, а этаж широкий и низкий. Отдать холсту всю высоту
значило бы показывать мир в треть экрана, а остальное залить чёрным.
Поэтому **стоймя** холст занимает верхние две трети, а нижняя треть отдана
управлению целиком: ряд стихий под полем, крупный ПУСК под правым большим
пальцем, счёт и служебные кнопки — в пустом левом углу. Наверху экрана
каждый пиксель игровой, и закрывать его счётом нельзя: именно там стоит
игрок.

**Боком** полоса не нужна и вредна — высоты и так мало. Поле занимает весь
экран, стихии уходят столбиком влево, ПУСК вправо, оба в углы, где и лежат
пальцы.

Масштаб доводится до того, при котором мир закрывает холст. Прежняя формула
смотрела только на размер экрана, и на телефоне выходило издевательство:
этаж в одиннадцать клеток высотой занимал треть вытянутого экрана.

Подписи на кнопках стихий на телефоне — имена, а не клавиши: никакой
стрелки влево там нет, и обещать её нечестно. Подсказки тоже знают, чем
играют: пальцу не предлагают жать пробел.

## Магия

Единственный способ убивать. Заклинание не лежит в инвентаре: его набирают
в очередь прямо в бою стрелками — до трёх стихий, — и пробел выпускает то,
что набралось.

У заклинания две независимые оси, и это главное правило всей игры:

* **состав** — какие стихии набраны — решает **вещество**: что прилетело;
* **узор** — в каком порядке — решает **форму**: куда прилетело.

Порядок в состав не входит намеренно. «Вода-ветер» и «ветер-вода» — одна и
та же стужа, иначе игроку пришлось бы помнить, что это разные жидкости, а
такое знание не выводится, а зубрится. Зато стужу можно выпустить плевком,
конусом или лучом — и это три разных инструмента из одной пары стрелок.

Одиночный плевок — базовый ответ: быстрый, дешёвый и **тихий**, на нём
держится тихая игра. Всё, что длиннее, слышно через стены.

Набор стоит времени: каждая стихия занимает 0.15 секунды, и всё это время
игрок замедлен вдвое, а очередь горит у него над головой — клетка наливается
цветом, пока стихия набирается, и подпись рядом говорит, что именно сейчас
в руке. Заряженного
видно, и враги на это отвечают — громила ускоряется, стрелок жмёт раньше.
Длина очереди тут не настройка, а ставка.

Форму задаёт узор, а не длина: умирают все одинаково, разной бывает только
геометрия попадания.

| очередь | форма | что делает |
|---|---|---|
| одна | ПЛЕВОК | быстрый снаряд, близко |
| две одинаковые | СГУСТОК | дальше и сквозь одного |
| две разные | ВЫДОХ | конус перед собой |
| две и третья | ЗАЛП | веер из трёх |
| три одинаковые | ЛУЧ | линия через комнату, но с замахом — её видно всем |
| края одинаковые | ПРОБОЙ | идёт сквозь тела, стекло и мебель |
| три разные | ВСПЫШКА | круг вокруг себя; в тесноте достанет и тебя |

### Вещества

Пять стихий дают 25 составов. Выписаны руками не все: каждая стихия несёт
черты (жжёт, мочит, толкает, ломает, бьёт разрядом), черты складываются, а
именем и своим лицом наделены те смеси, у которых оно есть.

| | огонь | вода | ветер | земля | молния |
|---|---|---|---|---|---|
| **огонь** | ОГОНЬ | ПАР | ЖАР | ЛАВА | ПЛАЗМА |
| **вода** | | ВОДА | СТУЖА | ГРЯЗЬ | РАЗРЯД |
| **ветер** | | | ВЕТЕР | ПЕСОК | ГРОМ |
| **земля** | | | | ЗЕМЛЯ | МАГНИТ |
| **молния** | | | | | МОЛНИЯ |

Тройки идут поверх: ТУМАН, ГЕЙЗЕР, ПЕРЕГРЕВ, ПЕПЕЛ, СМЕРЧ, ВУЛКАН,
МЕТЕЛЬ, ГРОЗА, ЗЫБУН, БУРЯ.

Тройной состав всегда даёт вспышку — узор «три разные» другой формы не
знает. Поэтому **ветер в составе уносит вспышку вперёд**: без этого десять
самых интересных веществ оказывались одной и той же кнопкой паники, и
ГРОЗУ нельзя было бросить, только подорвать под ногами. Носителем стал
ветер, потому что он и так отвечает за дальность, — и что полетит, видно
прямо по составу, а не по заученному списку. Своих брошенная вспышка не
разбирает так же, как и та, что рвётся под ногами.

Смесь — это третье, а не сумма двух. Пар не жжёт и не мочит: если бы
«огонь+вода» оставалось механическим сложением, скрещивать было бы незачем.
Прогон это и проверяет — у пара не должно оказаться ни `burn`, ни `wet`.

### Поле: вещество живёт после попадания

Заклинание не заканчивается ударом. Смесь оставляет след, и он лежит на
полу секундами — этим состав из выбора снаряда превращается в ход.

| на полу | что делает |
|---|---|
| ЛУЖА | мочит, проводит разряд, тушит горящего |
| ПОЖАР | поджигает всех, кто в нём стоит; враги его обходят |
| ЛЁД | не убивает, но по нему заносит; растаяв, оставляет лужу |
| ГРЯЗЬ | вязнут все, зато она не горит — единственное укрытие от огня |

Правила встречи читаются как правило природы, а не как список исключений:
огонь и вода дают пар, мороз превращает лужу в лёд, огонь топит лёд
обратно в лужу. Пожар при этом **не расползается** — расползающийся огонь
превращает бой в лотерею, а так им можно пользоваться как стеной.

**Одна стихия — это удар, две и больше — вещество.** Своего чистая стихия
не оставляет; изменить чужое ей по-прежнему хватает — вода тушит, огонь
выпаривает лужу и топит лёд. Правило появилось не из вкуса: пока чистый
огонь клал пожар с каждого плевка, самый дешёвый и самый частый ответ
засеивал смертью ту дорогу, по которой игрок и шёл дальше. Прогон поймал
это раньше глаз — бот сгорел в своём же следе на второй минуте.

Огонь не убивает мгновенно, а поджигает: горящий бежит и умирает на бегу,
и всё это время у него есть выход — лужа или грязь. По букве правила «все
умирают с одного касания» честнее была бы мгновенная смерть, но она отняла
бы у воды единственное применение, ради которого её носят.

Разряд идёт по воде. Сначала под током оказывается вся связная лужа, потом
ток перескакивает на мокрых рядом и с них дальше — и своих цепь не
разбирает. Лужа, налитая заранее, превращает одиночный разряд в оружие по
площади; собственная лужа под ногами превращает его в самоубийство.

Состояние видно на теле, а не только на полу. Маг, стоящий в веществе или
облитый им, слабо светится его цветом: синим — мокрый, оранжевым — в огне,
бледным — на льду, глухо-жёлтым — в грязи. Считать это глазами по клеткам
под ногами нельзя: тела движутся, а мокрыми остаются ещё три секунды после
того, как вышли из лужи.

Мокрый вдобавок обведён пунктиром цвета молнии — это единственное
состояние с готовым ответом, и подписано оно цветом ответа. Пунктир
появляется, только если молния у игрока есть: подсказка к тому, чего нет в
руках, — обещание, которого игра не держит.

### Свет

Ночь — не палитра, а слой: поверх кадра ложится тьма, и источники прожигают
в ней дыры. Разница с «нарисуем пятно под фонарём» принципиальная. Пятно
светлело поверх, и без источника было ровно так же светло; теперь без
источника темно, и фонарь, костёр или собственный посох — единственное,
что видно.

Светят фонари на оградах, горящий пол, заряженный маг, свечение стойкости
у врагов, летящие заклинания и вспышки. Пожар при этом освещает комнату:
по зареву видно, что где-то горит, — раньше об этом сообщала только сама
клетка, на которую надо было смотреть.

Проходов два. Первый выжигает тьму — он показывает, где светло. Второй
кладёт цвет — он показывает, каким оно светится. Без второго огонь и разряд
освещали бы одинаково белым, и цвет стихии, главный язык игры, пропадал бы
ровно там, где он ярче всего.

Пар и пыль не убивают — они прячут, и прячут всех одинаково. Взгляд ходит
через одну дверь: конус врага, наводка, выдох и вспышка спрашивают её же,
поэтому «за паром не видно» не приходится помнить в пяти местах, и своим
же паром можно ослепить себя.

### Предметы со своей стихией

В парке стоят вещи, которые ломаются ровно одним веществом. Это правило
комнаты, а не боя: игрок читает форму предмета и понимает, что набирать.

| предмет | берёт | что остаётся |
|---|---|---|
| БОЧКА | огонь, молния, земля | вода разливается на девять клеток вокруг |
| СТОГ | огонь | пожар, и он перекидывается на соседние стога |
| ВАЛУН | земля | проход и обзор, которых не было |
| КРИСТАЛЛ | молния | разряд по всему, что рядом мокрое |

Разница между «ломается многим» и «ломается одним» — это и есть вся тактика
вокруг предметов. Тонкая бочка поддаётся многому, валун и кристалл — ровно
одному, и в этом их смысл: они не препятствие, а вопрос «чем именно».

Проверяется черта вещества, а не стихия: лаву и жар роднит огонь, и оба
вскрывают бочку. Перечислять составы поимённо значило бы править список
при каждой новой смеси.

Бочка нужна не тем, что исчезает, а тем, что остаётся после неё: это
способ налить воды туда, куда сам не дотянешься. Разряд, вскрывший её,
идёт по той воде, которую сам и вылил, — одно нажатие, три следствия.

Стог не видно насквозь, но пройти сквозь него можно: это укрытие, в
котором стоят. Тем и страшнее, когда он занимается — и вместе с ним вся
копна, потому что солома поджигает солому.

### Этаж спит, пока смерть не заметили

Пока на этаже никто не убит **на глазах или в пределах слышимости**, на
игрока смотрят и не трогают. Это та половина игры, которой не хватало:
комнату можно обойти, разглядеть, что где стоит, и подготовить ход — а бой
начинается тогда, когда его начал ты.

Тревогу поднимает не смерть, а **замеченная** смерть. Видел — если живой
смотрит в ту сторону и между ними нет стены; слышал — если он ближе, чем
падает тело. Второе намеренно куда короче первого: иначе «тихо» не
существовало бы, а на маленьком этаже слышно было бы всё и всегда.

Тело при этом падает шумно всегда. Услышавший пойдёт посмотреть, что
упало, — и это единственная плата за убийство в стороне.

### Стихии открываются постепенно

Этаж выдаёт стихии сам — это поле формата, а не свойство игрока.

| этаж | что даёт | чему учит |
|---|---|---|
| ВХОД В ПАРК | огонь, молния | вода приходит не из рук, а из бочки |
| ПАВИЛЬОН «ЛЕДЯНОЙ» | + вода | пар: смесь — третье, а не сумма двух |
| ОРАНЖЕРЕЯ «ЛЁД» | + ветер | дальность, стужа, лёд под ногами |
| СКЛАД «КАМЕНЬ» | + земля | тяжесть, лава, грязь как укрытие от огня |
| ПОДСТАНЦИЯ | всё | пять стихий разом |

Порядок открытия — порядок обучения, и начинается он не с воды. Обучалка
даёт огонь и молнию, а воду выдаёт комната: бочка, вскрытая огнём,
разливает лужу под ногами у врага, и разряд в эту лужу забирает троих
разом. Так первое, что игрок узнаёт про игру, — что стихии работают друг
через друга, а не по очереди.

Подсказки обучалки идут по событиям мира, а не по таймеру: про бочку
игрок узнаёт, когда убил первого, про молнию — когда вода уже на полу.
Сказанное заранее не запоминается.

Подсказка на экране перечисляет только то, что этаж даёт, и кнопки
недоступных стихий не показываются: недоступная кнопка — обещание,
которого игра не держит.

### Книга заклинаний

Двадцать пять составов и десять именных заклинаний — до книги всё это было
скрытым содержимым: игра их считала, а игрок о них не знал. Разница между
«в игре есть двадцать пять веществ» и «ты нашёл девять из двадцати пяти»
здесь вся, какая есть: первое никого не держит, второе показывает пустые
клетки, и их хочется закрыть.

Книга открывается на `B` и ничего не открывает и не запрещает: набрать
можно что угодно с первой секунды, записывается только то, что уже
выпускал. Это не дерево умений — незнание тут не стена, а незаполненная
строка. Неоткрытая клетка показывает форму пустоты: сколько стихий в
составе. Пустая клетка не зовёт, «состав из трёх, а у тебя таких десять» —
зовёт.

**Именные заклинания** — второй ярус. Сигнатура это конкретная пара
«вещество · форма», у которой есть своё имя и своя добавка: огонь-земля-огонь
даёт БОРОЗДУ, а огонь-огонь-земля уже нет, потому что это другая форма.
Ключ — пара, а не сама последовательность: одну и ту же пару даёт несколько
порядков, и требовать угадать, какой из них «настоящий», было бы
издевательством.

| именное | это | что делает |
|---|---|---|
| БОРОЗДА | лава · пробой | лава ложится по всему пути, а не там, где встала |
| ЛЕДОСТАВ | стужа · пробой | ледяная полоса через всю комнату |
| ПЕСКОСТРУЙ | песок · пробой | сносит мебель и стекло на всей линии |
| ХВАТКА | магнит · выдох | стягивает всех перед собой в кучу |
| ОТБОЙ | гром · выдох | сдувает всех перед собой |
| РАЗРЯДНИК | молния · луч | бьёт по воде из каждой точки луча |
| РУСЛО | вода · луч | чистая вода стелет русло — заготовка под молнию |
| ПАЛ | огонь · луч | чистый огонь оставляет за собой пожар |
| ШТОРМ | гроза · вспышка | мочит, бьёт и расшвыривает разом |
| ЗАВЕСА | туман · вспышка | пар на полкомнаты: этаж перестаёт тебя видеть |

РУСЛО и ПАЛ нарушают правило «чистая стихия своего не оставляет» — и это
намеренно: найденное заклинание имеет право быть исключением, на том и
держится смысл искать.

Добавки объявлены флагами, а не кодом: мир умеет пять вещей — стелить след
по всему пути, тянуть, толкать, бить разрядом вдоль луча и класть вещество
там, где чистой стихии не положено. Одиннадцатая сигнатура не потребует
править мир, если обойдётся этими пятью.

Книга живёт в браузере рядом с рекордами. Приватный режим её потеряет — и
это допустимо: книга не пропуск, а память.

Стойкость. Враг светится своей стихией — и она же его защищает: этим
цветом его не убить. Огнём по огненному он отобьёт, хоть одной, хоть тремя
подряд: это стойкость, а не щит с зарядами, и количество её не пробивает.
Нужен любой другой цвет, а в смешанной очереди хватает одного чужого.

Правило работает во все стороны: порча врага не убивает его же союзника
той же стойкости. Никакого круга превосходств — «бей не тем, чем он
светится» читается прямо с экрана и не требует заучивания.

Дальнобойные враги швыряются той же магией, что и игрок: одной стихией,
без очереди, с замахом. По цвету снаряда сразу видно, чем этого брать
нельзя.

### Цена очереди посчитана, а не прикинута

Прогон `tests/sim.mjs` меряет, за сколько один и тот же набор врагов
умирает от одиночных плевков и от одной вспышки. Правило, которое
проверяется: на одиночной цели плевок быстрее (0.27 против 0.72 секунды),
на пятерых окупается длинная очередь (0.72 против 1.40).

Первая версия этой проверки поймала настоящую ошибку — тогда у игрока ещё
была бита, и один её взмах убивал всех в секторе сразу. Очередь, стоящая
почти секунду уязвимости, оказывалась строго хуже бесплатного удара, и на
глаз это было не видно: играется бодро и так.

Идея узоров AAA / ABA / ABC пришла из [«Битвы Стихий»][bitva], где они
работают в пошаговом обмене. Код оттуда не переносился: там узор даёт
урон и заряды, здесь — форму попадания, и перенос чужой семантики дал бы
механику, которая выглядит как та, но врёт. Круг «камень-ножницы-бумага»
не взят сознательно: он держится на том, что ходы делают вслепую, а в
реальном времени ему не на чем стоять.

[bitva]: https://github.com/aka-gst/bitva-stihiy

## Счёт

Очки платят не за аккуратность, а за темп. Убийство стоит 100, добивание
лежачего — 150, и всё это множится на длину цепочки: каждое следующее
убийство поднимает множитель, четыре секунды без крови обнуляют его.
Врага, которого застрелил свой же, засчитывают за 50 — заслуга косвенная.

В конце этажа добавляются бонусы: за время быстрее норматива
(15 секунд плюс 7 на каждого), за разные орудия, за максимальную цепочку,
за пройденный без единого выстрела этаж и за победу с первой попытки.

Ранг считается от норматива в 900 очков на врага: S с 1,2 норматива,
дальше A, B, C и D. Тупой бот, зачищающий этаж по прямой, набирает C —
всё, что выше, требует цепочек и добиваний.

Рекорд хранится в браузере и привязан не к названию этажа, а к его коду:
чужой уровень, пришедший ссылкой, заводит собственную строку.

## Вызов по ссылке

Единственное в этой игре, что один человек может отправить другому.

После сданного этажа игра показывает ссылку. В ней лежит и сам этаж, и
результат отправителя:

```
/avto/#l=<код этажа>&c=<ник>~<десятые секунды>~<очки>~<ранг>
```

Кто откроет — попадёт ровно на тот же этаж, увидит на экране «GST прошёл за
0:41.2, ранг A» и будет видеть чужое время в углу, пока бежит. Свой
результат он отправит обратно той же кнопкой.

Ни сервера, ни входа, ни таблицы рекордов для этого не нужно: всё, что
нужно обоим, уже лежит в адресной строке. Ссылка, отправленная год назад,
откроется и завтра — ровно как код этажа.

Вызов намеренно не подписан и не защищён. Подделать своё время в дружеском
споре можно и без нас, а криптография сделала бы ссылку длиннее без
единого выигранного спора.

Разбор адреса проверяется отдельным прогоном: ссылку режут, склеивают и
правят руками чаще, чем кажется, поэтому порядок частей не фиксирован, а
обрезанный вызов не должен ронять игру.

## Свой этаж

Пока редактора нет, этажи рисуются картинкой в `src/levels.js`:

```
# стена   . пол    , ковёр   = мебель   | стекло
+ дверь   X выход  @ вход    t громила  s стрелок
f носитель огня   w носитель воды   v носитель ветра
```

Строки должны быть одной длины, вход `@` обязателен. Проверка связности —
в прогоне `tests/sim.mjs`.

## Защита от утечек

Репозиторий публичный, поэтому проверка на секреты и личные данные стоит в
`git`, а не держится на внимательности — тот же хук, что и на сайте:

```sh
git config core.hooksPath .githooks
mkdir -p ~/.config/aka-gst && cp .githooks/private-words.example ~/.config/aka-gst/private-words.txt
chmod 600 ~/.config/aka-gst/private-words.txt
```

Список лежит вне дерева игры: она копируется на сервер файлами, а не
индексом git, и внутри `.githooks/` он оказался бы на публичном хостинге.

## Проверка

```sh
node tests/sim.mjs
node tests/input.mjs
node tests/challenge.mjs
node tests/book.mjs
```

Первый прогоняет бой без браузера: удары, выстрелы, поиск пути, полную
зачистку ботом, начисление очков и бюджет кадра. Второй подсовывает вводу поддельный DOM и
проверяет клавиши, стики и экранные кнопки.

Ни requestAnimationFrame, ни холст в прогонах не участвуют — они молчат
о том, как игра выглядит, но говорят, работает ли она.
